# Paper Library Reader — GitHub Pages build

This folder is ready to upload as the root of a public GitHub repository and
publish with GitHub Pages.

Paper Library reads EPUB, DRM-free MOBI, and PDF files. Uploaded files,
progress, bookmarks, notes, and preferences remain in each visitor's browser
storage; they are not uploaded to GitHub or shared with the site owner.

Public-domain discovery uses Gutendex/Project Gutenberg. Other configured
catalogues open their official websites. The application and pinned
open-source reader libraries are included locally so no paid backend is
required.

Read `GITHUB-PAGES-SETUP.md` for exact publishing steps and
`TECHNICAL-DOCUMENTATION.md` for architecture, dependencies, security, tests,
mobile behavior, and known limitations.
