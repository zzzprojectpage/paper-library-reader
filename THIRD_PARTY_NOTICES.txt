Catalogue metadata
------------------
Gutendex is an independent JSON API for Project Gutenberg metadata:
https://gutendex.com/

Project Gutenberg usage and trademark terms apply. Public-domain status varies
by jurisdiction; the application excludes records marked copyright=true by the
API and displays a jurisdiction warning.

External catalogue links
------------------------
The application links to the following official catalogue pages:

- ePubBooks: https://www.epubbooks.com/
- Standard Ebooks: https://standardebooks.org/ebooks
- Wikisource: https://en.wikisource.org/wiki/Main_Page
- Global Grey: https://www.globalgreyebooks.com/
- Directory of Open Access Books: https://www.doabooks.org/

It does not fetch, scrape, copy, or bundle their catalogue records or content.
Users must review rights, licences, download terms, and available formats at
each source.
